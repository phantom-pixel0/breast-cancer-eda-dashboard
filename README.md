# Breast Cancer EDA Dashboard

## Project Overview
This project explores a breast cancer dataset through Exploratory Data Analysis (EDA) and an interactive Streamlit dashboard.

The goal is to understand the dataset, examine tumour characteristics and recorded patient outcomes, and present useful observations through data analysis and visualizations.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Streamlit
- Google Colab
- Visual Studio Code

## Project Files
- `app.py` – Streamlit dashboard application.
- `requirements.txt` – Required Python packages.
- `Breast_Cancer_Cleaned.csv` – Cleaned dataset used by the dashboard.
- `Breast_Cancer_EDA.ipynb` – Google Colab notebook containing the analysis.
- `README.md` – Project documentation.

## How to Run the Dashboard

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run app.py
```

## Project Purpose
This is an educational data analytics project. The analysis is for learning and exploration and is not intended for medical diagnosis or clinical decision-making.
